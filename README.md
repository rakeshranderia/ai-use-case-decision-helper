# AI Use-Case Decision Helper

A lightweight browser-based project that turns a proposed AI use case into a simple, documented decision.

The project follows:

**Use Case → Data Classification → Platform → Impact → Controls → Decision → Review**

## Why this exists

AI governance often becomes either:

- too loose — “just use it”; or
- too heavy — every idea requires a large risk process.

This project demonstrates a middle ground: ask the important questions early, make the decision visible, and escalate only when the data, platform or potential impact justifies it.

## Decisions

The helper returns one of four outcomes:

- **Proceed**
- **Proceed with Controls**
- **Further Assessment Required**
- **Do Not Proceed**

## Technology

- HTML
- CSS
- Vanilla JavaScript
- No backend
- No external libraries
- No data is transmitted anywhere

## Running locally

Open `index.html` in a browser.

## Portfolio positioning

This is intended as a practical technology-leadership / AI-governance project rather than a production compliance product.

It demonstrates how a governance framework can be translated into a small, understandable decision tool.
